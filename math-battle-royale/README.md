# 🎮 数学大逃杀 Math Battle Royale

一个创新的初中数学教学游戏，将战术竞技游戏元素与数学知识完美结合。

## 📖 项目简介

本项目基于最新 Web 前端技术（React + TypeScript + Three.js），实现了五个阶段共 12 个关卡的数学学习游戏。学生通过在"战场"中解决数学问题来完成游戏任务，让抽象的数学概念变得生动有趣。

## 🎯 教学目标

### 第一阶段：新兵入伍（七年级上册）
- **核心武器**：有理数、整式、一元一次方程
- 关卡 1：精准跳伞——有理数加减运算 ✓ (已实现)
- 关卡 2：背包管理学——整式与一元一次方程 (开发中)
- 关卡 3：生死时速——一元一次方程追及问题 (开发中)

### 第二阶段：侦察尖兵（七年级下册）
- **核心武器**：平面直角坐标系、二元一次方程组、不等式组
- 关卡 4：小地图标点——平面直角坐标系 (规划中)
- 关卡 5：双耳定位——解二元一次方程组 (规划中)
- 关卡 6：多障碍跑毒——一元一次不等式组 (规划中)

### 第三阶段：特种精英（八年级下册）
- **核心武器**：勾股定理、一次函数、数据分析
- 关卡 7：房区战术——勾股定理求最短路径 (规划中)
- 关卡 8：移动靶预判——一次函数与方程组 (规划中)
- 关卡 9：武器大师——加权平均数与伤害期望 (规划中)

### 第四阶段：王牌特训（九年级上册）
- **核心武器**：二次函数、圆与概率
- 关卡 10：迫击炮手——二次函数与抛物线 (规划中)
- 关卡 11：天命圈玄学——圆面积比与概率 (规划中)

### 第五阶段：战神终极考（九年级下册）
- **核心武器**：相似三角形、反比例函数
- 关卡 12：狙击镜测距——相似三角形与反比例函数 (规划中)

## 🚀 技术栈

- **框架**: React 18 + TypeScript
- **构建工具**: Vite 8
- **3D 引擎**: Three.js
- **样式**: CSS Modules / Inline Styles
- **包管理器**: npm

## 🛠️ 开发指南

### 环境要求
- Node.js 18+ 
- npm 9+

### 安装依赖
```bash
cd math-battle-royale
npm install
```

### 启动开发服务器
```bash
npm run dev
```

访问 `http://localhost:3000` 查看应用。

### 构建生产版本
```bash
npm run build
```

### 预览生产构建
```bash
npm run preview
```

## 🎮 当前功能

### 关卡 1：精准跳伞 (已完成)
- ✅ 3D 场景渲染（飞机、地面、山地、海平面）
- ✅ 动态跳伞动画
- ✅ 开伞机制演示
- ✅ 海拔高度可视化标签
- ✅ 两个数学任务交互答题
- ✅ 实时反馈系统
- ✅ 关卡完成进度追踪

#### 数学知识点
- 有理数减法法则：`相对高度差 = 飞机高度 - 地面高度`
- 负数的实际意义：海拔低于海平面用负数表示
- 应用题建模：`开伞海拔 = 地面海拔 + 安全高度`

#### 正确答案
1. 相对高度差：**805m** (800 - (-5) = 805)
2. 开伞海拔高度：**195m** (-5 + 200 = 195)

## 🌟 特色亮点

1. **沉浸式学习体验**：3D 游戏场景让学生身临其境
2. **渐进式难度**：从简单到复杂，符合认知规律
3. **即时反馈**：答题后立即获得正误反馈
4. **进度追踪**：解锁机制激励学生持续学习
5. **跨平台兼容**：浏览器即可运行，无需安装

- 使用 Three.js 实例化渲染减少 Draw Call
